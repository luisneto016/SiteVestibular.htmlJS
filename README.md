# SiteVestibular.htmlJS

Site feito junto a uma proposta feita por alunos da UNICAMP quando vieram a uma visita ao SESI. Pedimos a inteligência artificial para fazer um site para estudos para o vestibular para diversas matérias, com uma pequena introdução teórica, indicações de vídeos no Youtube e um sistema de calendário para organização pessoal. Pedimos também um sistema de perfil, onde você pode editar o seu personagem e ganhar pontos quanto mais você entra no site, junto a um sistema de ofensivas idêntico ao Duolingo.
